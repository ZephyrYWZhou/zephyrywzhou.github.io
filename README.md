# zephyrywzhou.github.io

Personal site and blog, built by GitHub Pages with Jekyll (minima theme).

## Add a post

1. Create `_posts/YYYY-MM-DD-title.md` with this header:

   ```
   ---
   layout: post
   title: "My title"
   date: YYYY-MM-DD
   ---
   ```

2. Write the post in Markdown below the header.
3. Commit and push to the `gh-pages` branch. The site rebuilds in about a minute.
